# Student Score Prediction
Predict exam score of a student based on the study hours using Linear Regression

## Dataset
Dataset is from kaggle: https://www.kaggle.com/datasets/grandmaster07/student-exam-performance-dataset-analysis

## Linear Regression 
Linear regression is a supervised machine learning algorithm. In this project, the model will learn the relationship between the number of hours studied and the marks scored by the student. The equation of the linear regression is:
y = mX + b
y is the dependent variable (Exam score)
X is the independent variable (Number of hours studied)
m is the slope (how y changes for a unit change in X)
b is the intercept (the value of y when X is zero)

## Steps:
1. Import necessary libraries
2. Load the dataset
3. Separate input and output variables
4. Train the Linear Regression model
5. Predict the exam scores
6. Visualize

## How to run
Open the norebook in Google Colab -> Upload the csv file of the dataset downloaded from the kaggle -> run the cell sequentially
